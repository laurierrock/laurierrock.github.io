プライバシーポリシー

SDcard-to-GooglePhoto（以下「本ツール」）は、作成者本人が個人的に使うためのツールです。

利用するデータ

本ツールは、Google Photos Library API の photoslibrary.appendonly 権限のみを使い、利用者本人のパソコンに挿したSDカード内の写真を、利用者本人のGoogleフォトに追加します。既存の写真の閲覧・変更・削除は行いません。

データの保存と共有

写真や認証情報が作成者や第三者のサーバーに送られることはありません。認証情報は利用者本人のパソコン内にのみ保存されます。データを第三者に販売・共有・広告に利用することはありません。

権限の取り消し

Googleアカウントの「サードパーティ製のアプリとサービス」から、いつでも本ツールの権限を取り消せます。

Privacy Policy

SDcard-to-GooglePhoto is a personal tool used only by its author. It uses only the Google Photos Library API scope photoslibrary.appendonly to add photos from the user's own SD card to the user's own Google Photos library. It does not read, modify, or delete existing photos. No photos or credentials are sent to the author or any third party; credentials are stored only on the user's own computer. No data is sold, shared, or used for advertising. Access can be revoked at any time from the "Third-party apps & services" page of the Google Account.
